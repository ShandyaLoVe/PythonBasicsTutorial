Cours 5 : Fonctions¶

Vous avez déjà utilisé de nombreuses fonctions dans Python, par exemple type, print, help et des fonctions des bibliothèques numpy (par exemple np.linspace) ou matplotlib.pyplot (par exemple plt.plot).

Comme tous les langages de programmation, Python vous permet de définir aussi vos propres fonctions, ce qui peut servir à

  • rendre le code plus concis et lisible en remplaçant des blocs de code par des fonctions aux noms explicites (par exemple developpement_limite ou fibonacci ou trace_un_joli_graphe...)
  • surtout éviter de taper plusieurs fois le même code si vous voulez effectuer plusieurs fois les mêmes actions mais avec des paramètres différents.

Les fonctions en Python permettent de nombreuses possibilités, dont une présentation assez complète est donnée la page https://courspython.com/fonctions.html. Cette fiche de cours liste les principales et donne quelques exemples.

1 - Définition et appel d'une fonction :¶

Les fonctions regroupent plusieurs instructions. En Python, elles peuvent se définir à la volée (à n'importe quel endroit d'un script) même si il est d'usage de les définir en tête de script ou dans un script dédié (un module) qu'on peut appeler ensuite comme les autres bibliothèques. Les instructions sont exécutées quand la fonction est ensuite appelée (et pas avant ! Notamment définir une fonction n'éxécute pas les instructions).

Donnons un premier exemple :

In [1]:
# Définition d'une fonction 
def compte_jusque_cinq():              # deux points et indentation (comme pour les boucles)
    
    """Affiche les entiers de 1 à 5""" # aide (accessible ensuite avec help)
    
    for i in range(5):                 # instructions internes à la fonction
        print(i+1)

On a utilisé :

  • le mot-clef def suivi du nom qu'on donne à la fonction ;
  • le symbole : et une indentation pour entrer dans le corps de la fonction (comme pour les boucles) ;
  • un paragraphe entre """ qui décrit la fonction, et qui pourra être affiché avec help (c'est comme ça que sont écrites toutes les fonctions natives : help affiche le pararaphe écrit au niveau de la fonction)

Notez que définit la fonction, de nom compte_jusque_cinq, mais on n'a pas exécuté les instructions. C'est similaire à une affectation de variable par exemple a=3. Si on utilise print, on voit que compte_jusque_cinq contient bien une fonction. On peut ensuite utiliser help pour avoir accès à la description qu'on a tapée, et appeler la fonction pour voir le résultat :

Paramètres et sorties¶

Ci-dessus, on a défini une fonction sans argument qui ne fait qu'exécuter un bloc d'instructions. La plupart des fonctions cependant,

  • prennent en entrée un ou des paramètres,
  • renvoient une ou des variables en sortie.

Dans ce cas,

  • les paramètres sont indiqués après le nom de la fonction entre ( )
  • les sorties suivent le mot-clef return,
  • on précise dans l'aide de la fonction quels sont ces paramètres et sorties,
  • on peut utiliser la fonction comme les autres fonctions à droite d'un signe = pour affecter la sortie à une variable.

Par exemple :

In [3]:
 def eleve_au_carre(x): 
     """ Cette fonction calcule le carré d'un nombre ou d'un tableau 
     (composante par composante dans le cas d'un tableau)
          
     Paramètre :
         x : nombre ou tableau (np.array)
     Renvoie :
         y : x **2 ou tableau y tel que y_j = (x_j)**2 si x est un tableau
     """
     y = x**2     # y est une variable locale (interne a la fonction)
     return y     # instruction " return " pour renvoyer le resultat

print("*** Aide de la fonction :")
help(eleve_au_carre)

# Quelques opérations
import numpy as np

x2 = eleve_au_carre(4.)
print("*** Fonction appliquée au réel 4. :", x2)

v = np.array([1,2,3])
v2 = eleve_au_carre(v)
print("*** Vecteur v et fonction appliquée à v :\n", v,"\n", v2)

A = np.array([[1., 2.],
              [-2., 5]])
A2 = eleve_au_carre(A)
print("*** Matrice A et fonction appliquée à A : \n",A,"\n",A2)

Multiples paramètres et sorties¶

Comme dit ci-dessus, une fonction peut aussi

  • prendre en entrée plusieurs paramètres (séparés par des virgules)
  • renvoyer plusieurs variables en sortie (également séparées par des virgules après return).

Dans le cas de plusieurs sorties,

  • soit on les affecte à une seule variable qui contiendra un tuple avec toutes les sorties
  • soit on les affecte à autant de variables qu'il y a de sorties en les mettant à gauche du signe =

Par exemple :

In [4]:
 def somme_et_produit(x,y): 
     """ Cette fonction renvoie la somme et le produit de deux nombres ou tableaux 
    (composante par composante dans le second cas)
     
     Paramètres :
         x,y : nombres ou tableaux (np.array) de même taille
     Renvoie :
         somme : somme x+y ou tableau s tel que s_j = x_j + y_j si x et sont des tableaux
         produit : produit x*y ou tableau p tel que p_j = x_j * y_j si x et sont des tableaux
     """
     somme = x+y
     produit = x*y
     return somme, produit # deux sorties, séparées par des virgules

# Quelques opérations
v1 = np.array([1,2,3])
v2 = np.array([3,4,5])

# Avec une seule variable de sortie
vsp = somme_et_produit(v1,v2)
print("*** Fonction appliquée aux vecteurs v1 et v2 : \n", vsp)
print("\n --> on voit que la fonction renvoie un tuple contenant les deux sorties")

# Avec deux variables de sortie (dans le même ordre que le return) :
vs, vp = somme_et_produit(v1, v2)
print("\n*** En utilisant deux variables pour stocker les sorties :")
print("vs = ",vs)
print("vp = ",vp)

*** Fonction appliquée aux vecteurs v1 et v2 : 
 (array([4, 6, 8]), array([ 3,  8, 15]))

 --> on voit que la fonction renvoie un tuple contenant les deux sorties

*** En utilisant deux variables pour stocker les sorties :
vs =  [4 6 8]
vp =  [ 3  8 15]

2 - Variables locales et globales¶

Quand on utilise des fonctions (et dans d'autres situations), il est important de distinguer deux types de variables :

  • les variables globales définies dans le corps du script, accessibles partout y compris dans les fonctions,
  • les variables locales définies uniquement dans une fonction, qui ne sont pas accessibles en-dehors de cette fonction.

Un exemple avec le code suivant :

In [5]:
a = 2.                # a est une variable globale ...
print("a = ", a)     

def produit_par_a(x):
    y = a*x           # ... qu'on peut utiliser à l'intérieur d'une fonction
    return y

b = produit_par_a(5.)
print("b = ", b)

a =  2.0
b =  10.0

On voit que :

  • la variable globale a a été utilisée par la fonction au moment de l'appel b = produit_par_a(5.) qui a donné le résultat attendu,
  • par contre la variable locale y est inconnue en-dehors de la fonction,
  • le paramètre x de la fonction est aussi une variable locale (qui prend la valeur 5. lors de l'appel de la fonction).

Cette distinction entre nature des variables est très importante (et parfois source d'erreurs !).

On renvoie à https://courspython.com/fonctions.html pour des explications et exemples plus approfondis.

3 - Paramètres optionnels¶

Quand une fonction a beaucoup de paramètres, et que certains d'entre eux prennent souvent la même valeur, il peut être fastidieux de tous les entrer à chaque appel de la fonction. Python permet pour éviter ça de définir des paramètres optionnels en leur atribuant une valeur par défaut avec la syntaxe parametre=valeur (comme une affectation classique) dans la liste des paramètres.

Par la suite, à chaque appel de la fonction, la valeur par défaut sera utilisée si on ne donne que les paramètres obligatoires. Si on veut changer cette valeur, on utilise la même syntaxe parametre=autre_valeur lors de l'appel de la fonction.

Ci-dessous on donne un exemple avec une fonction qui trace un graphe (elle ne renvoie pas de sortie). Le but est de tracer avec cette fonction des figures "propres" (avec nom des axes, grille ...) en une ligne, étant donnés deux vecteurs : on ne veut pas recopier à chaque fois les lignes de mise en forme (plt.xlabel() etc.).

In [8]:
import numpy as np
import matplotlib.pyplot as plt 

# Définition de la fonction
def mon_graphe(x, y, mon_xlabel="$x$", mon_ylabel="$y$", mon_titre=None):
    """ Cette fonction trace un graphe et donne des noms aux axes, on peut
    aussi donner un titre au graphe
    
    Paramètres obligatoires :
        x, y : vecteurs de même taille (on trace y en fonction de x)
    Paramètres optionnels :        
        mon_xlabel , mon_ylabel : nom des axes (par défaut "$x$" et "$y$")        
        mon_titre : titre (par défaut None : pas de titre)
    """    
    FS = 14    
    plt.plot(x,y,'-k')     
    plt.grid("on")
    plt.title(mon_titre,fontsize=FS)
    plt.xlabel(mon_xlabel,fontsize=FS)
    plt.ylabel(mon_ylabel,fontsize=FS)

# Définition de trois vecteurs
vx = np.linspace(0, 1, 101)
vy1 = 1 - vx **2
vy2 = np.exp(vx)         

# Une figure avec deux subplots (et une seule ligne de code par subplot !)
plt.figure(1,figsize=(12,4))

plt.subplot(1,2,1)
mon_graphe(vx, vy1)  # ne donne que les paramètres obligatoires

plt.subplot(1,2,2)   # donne un ylabel plus spécifique et un titre 
mon_graphe(vx, vy2, mon_ylabel ="exp($x$)", mon_titre = "Graphe de la fonction exponentielle") 

plt.tight_layout()

4 - Fonctions comme paramètres d'autres fonctions¶

Enfin, les fonctions peuvent

  • appeler d'autres fonctions définies préalablement (elles sont dans l'espace global donc accessibles aux fonctions suivantes) ;
  • prendre en entrée d'autres fonctions, y compris des fonctions déjà existantes (par exemple des fonctions de numpy).

Prenons comme exemple encore une fonction de tracé de graphes de fonctions, mais qui

  • prend comme entrées :
    • une fonction dont on veut tracer le graphe représentatif (obligatoire),
    • un intervalle de tracé (optionnel),
    • le nom de cette fonction pour donner un titre à la figure (optionnel),
  • puis effectue les opérations suivantes :
    • crée deux vecteurs à partir de ces informations,
    • définit un titre qui précise le nom de la fonction et l'intervalle choisi,
    • utilise finalement la fonction mon_graphe définie ci-dessus pour faire le tracé.
In [9]:
def graphe_representatif(f, xmin=0, xmax=1, nom="F"):
    """ Cette fonction trace le graphe d'une fonction sur un intervalle donné
    
    Paramètre obligatoire :        
        f : fonction dont on veut tracer le graphe (doit accepter des np.arrays en entrée)
    Paramètres optionnels :
        xmin, xmax : intervalle de tracé (par défaut : 0 et 1)
        nom : nom de la fonction
    """
    x = np.linspace(xmin,xmax,200)                               # discrétise [xmin, xmax]
    y = f(x)                                                     # utilise la fonction donnée en paramètre
    titre = "Fonction "+nom+" sur ["+str(xmin)+","+str(xmax)+"]" # définit un titre
    mon_graphe(x,y,mon_titre = titre)                            # appelle mon_graphe pour le tracé

# Définit une fonction à tracer
def f1(x):
    """Une première fonction "en cloche" à tracer"""
    return x*(1-x)

# Une figure avec 3 subplots (avec une seule ligne de code par subplot !)
plt.figure(2,figsize=(15,5))

plt.subplot(1,3,1)
graphe_representatif(f1,nom="cloche")    # trace la fonction définie ci-dessus

plt.subplot(1,3,2)
graphe_representatif(np.sin,nom="sinus") # trace une fonction existante (np.sin ici)

plt.subplot(1,3,3)
graphe_representatif(np.sin,xmax=4*np.pi,nom="sinus") # change l'intervalle de tracé
                                                      # (il faut encore régler l'affichage du titre ...)
plt.tight_layout()                       # pour éviter que les subplot ne se chevauchent
