1 - Images as pixel arrays, display in Python¶

In image processing, an image is modeled by a array of pixels. Each pixel contains one or more numerical values representing its intensity or color.

Grayscale image¶

A grayscale image is represented by a 2D array of size $M\times N$, where each pixel takes an integer value between 0 (black) and 255 (white). This choice of 256 different values ​​allows information to be stored on one byte (8 bits) per pixel. The array of numpy are therefore very suitable for representing images.

Below we return to the example given in class of an image of $5\times 5$ pixels (in the course the values varied from 0 to 5, here we allow more nuances), which we define using a array and which we display with plt.imshow (and the option cmap=grey to display grayscale).

In [1]:
import numpy as np
import matplotlib.pyplot as plt

# Table of values
image = np.array([
       [  0,  51, 102, 153, 204, 255],
       [ 51,   0,  51, 102, 153, 204],
       [102,  51,   0,  51, 102, 153],
       [153, 102,  51,   0,  51, 102],
       [204, 153, 102,  51,   0,  51],
       [255, 204, 153, 102,  51,   0]])

# Display 
plt.figure(1)
plt.imshow(image,cmap = "grey")
Out[1]:
<matplotlib.image.AxesImage at 0x7618b0232900>

Note that with this display,

  • the axes are numbered in pixels
  • The numbering follows the convention for matrices:
    • the origin is at the top left of the image
    • the vertical axis is oriented from top to bottom (from line to line).

We can then manipulate the image with the functions known for tables: modify a value, or groups of values using slicing or masks. Some examples are given below and in the course (and will be covered in practical work).

Color image (RGB)¶

For a color image in RGB (Red, Green, Blue) format, each pixel is defined by three values: R (Red), G (Green) and B (Blue), which are also coded on one byte, therefore from 0 to 255. We could therefore represent such an image by three two-dimensional tables. But as we are not limited to two dimensions for computer tables, we instead use a single three-dimensional array of size $M \times N \times 3$. We can see this table as a superposition of three "layers" which are the three 2D tables R, G and B.

The code below illustrates building a $2\times 5$ pixel image "by hand". We also display images corresponding to tables R, G, B to visualize the intensity of each color.

In [3]:
# Example color image (2x5) 

# Definition of three tables R, G, B 
R = np.array([
    [255,   0, 128,  64, 192],
    [  0, 255,   0, 128,  64]])

G = np.array([
    [  0, 255,  64, 192, 128],
    [128,   0, 255,  64, 192]])

B = np.array([
    [ 64, 128, 255,   0, 192],
    [192,  64, 128, 255,   0]])

# Combination of channels to form RGB image
image_rgb = np.zeros((2,5,3)) # three-dimensional array
image_rgb[:,:,0] = R          # we assign the three tables to each of the “slices” of the table
                              #image_rgb
image_rgb[:,:,1] = G
image_rgb[:,:,2] = B

# Note: you can also use an advanced numpy function
# which "glues" the three tables into one line
image_rgb = np.stack((R, G, B), axis=-1)

# Display
plt.figure(figsize=(15, 5))

# Subgraph 1: RGB image
plt.subplot(1, 4, 1)
plt.imshow(image_rgb)
plt.title("RGB image")

# Subgraph 2: Red
plt.subplot(1, 4, 2)
plt.imshow(R, cmap='Reds')
plt.title(“Intensity of red”)

# Subgraph 3: Green
plt.subplot(1, 4, 3)
plt.imshow(G, cmap='Greens')
plt.title(“Intensity of green”)

# Subgraph 4: Blue
plt.subplot(1, 4, 4)
plt.imshow(B, cmap='Blues')
plt.title(“Intensity of blue”)
Out[3]:
Text(0.5, 1.0, 'Blue intensity')

2 - Import, display, local repository¶

Of course, we are not going to draw or generate complex images with Python code, but we are going to import existing images to work on it and extract information.

We take the example of the image "nautilus.png" downloaded to your working directory. You can check the presence of the image file with the unix command ls in Spyder's IPython console.

Below, we read this image with the function plt.imread (which transforms it into a table numpy), we display the shape (the dimensions) of the resulting table, then we display it with the function plt.imshow.

In [4]:
import numpy as np
import matplotlib.pyplot as plt

# Reads the image and saves it to the tab_image array 
tab_image = plt.imread('nautile.png')

# Gives the shape of the resulting table
print("Shape of the table: ", np.shape(tab_image))

# Display this image with matplotlib
plt.figure(1)
plt.imshow(tab_image)
plt.axis('equal')
plt.xlabel('columns',fontsize=14)
plt.ylabel('lines',fontsize=14)
plt.title('Nautilus',fontsize=14);

Table shape: (429, 462, 3)

The order print(np.shape(myimage)) returns the tuple (429,462,3). As seen above, tab_image is therefore a three-dimensional array: the first two dimensions correspond to the number of pixels in the image and the third dimension to the three colors R, G and B. This color image is a "stack" of three arrays (429,462) containing the levels between 0 and 255 for R, G and B.

The axes are always numbered in pixels (from 0 to 428 for rows, from 0 to 461 for columns).

In repository terms, the numbering convention means that

  • the image reference frame has its center at the top left of the image,
  • the length scale is the pixel
  • the y-axis is upside down compared to the usual Cartesian graph in mathematics.

This reference frame is shown below in cyan color and the axes are named “xpixel” and “ypixel”. It will be particularly important when we want measure distances on the image.
