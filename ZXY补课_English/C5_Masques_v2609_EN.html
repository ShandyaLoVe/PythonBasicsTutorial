Course 5: Masks¶

Combined with vectorization, the use of masks allows you to perform complex operations with an intuitive, very compact and elegant syntax. It is thus possible to replace with a single instruction an operation that would require combining both tests and loops.

The syntax is close to mathematical language but you have to understand the internal workings of the operations with the logic to avoid unpleasant surprises.

Below, we start by giving a first example of use, then we return in detail to the tools and syntax used.

1 - First example: subsets of vectors¶

To introduce the possibilities of masks, the easiest way is to take an example:

Below we define and represent a speed as a function of time. Let's imagine that this is the speed of a mountain biker measured over 6 minutes. The measurement is taken every 5 seconds, so there are 73 measurements.

In [1]:
import numpy as np
import matplotlib.pyplot as plt

# Time and speed vectors
t = np.linspace(0,6,73)
v = 5*(np.sin(t) + 1.8*np.sin(4*t) + 3) # (arbitrary function for example)

# Plot: we define a function that we will reuse later
def trace_vitesse(t,v):
    """ Plot the cyclist's speed v as a function of time t between 0 and 6 minutes. 
    Parameters:
        t,v: vectors (np.array) of times (in min) and speeds (in km/h) to trace
    """
    
    plt.plot(t,v,'.-')
    plt.grid()
    plt.xlim(0,6)
    plt.ylabel('Speed v [km/h]', fontsize=14)
    plt.xlabel('Time t [minutes]', fontsize=14);

plt.figure(1)
trace_vitesse(t,v)

We now wish extract the times and speed from the start of the journey, for a time less than 1 min, then put this part in black in thick lines on the curve, below. To do this, we first define a vector tstart containing the corresponding time values:

tdebut = t[(t<=1)]

Note here that between the square brackets t[ ], we put, instead of indices or table sections that we are used to, an expression in natural language. "I want to isolate a subpart of the table t whose components are less than 1".

Vectors t and v being the same size, we can also do that for the speed vector! "I want to isolate a subpart of the table v which corresponds to the times $t \leq 1$" gives:

Now we want to highlight speeds above 20 km/h and below 10 km/h, with green and red dots. This time we use the vector v to define the conditions inside the brackets. To be even more compact, we can directly type the expressions inside the plot:

In [6]:
# Definition of limits 
vrapide = 20 
vlente  = 10

# Plot
plt.figure(3)
trace_vitesse(t,v)                                        # Initial graph and formatting 
plt.plot(t[v>=vrapide],v[v>=vrapide],'og',lw=3, label=“Fast Speeds”)
plt.plot(t[v<vlente],v[v<vlente],'gold',lw=3, label=“Slow Speeds”)
plt.legend(fontsize=12)

Finally, we want to know for how many seconds the cyclist managed to go beyond 20 km/h.

In [7]:
print(“The cyclist was in excess of 20 km/h for:”+str(5*np.sum(v>20))+"seconds.") 
# The sum is multiplied by 5 because the measurements are taken every 5 seconds.

We see that this writing is very compact and particularly effective. Doing the same operation with loops and tests is possible but would have made the code considerably heavier.

This writing is compact but less easy to intuitive. You have to understand the workings of it to use it well.

2 - Operation details¶

You have to understand the basics of masks, you have to go back to very simple notions. In general, we create a logical variable, that is to say a boolean (True or False in Python) by writing a condition.

For example an inequality ($3>4$) which is false here:

In [8]:
condition = 3>4
print(condition)

False

We can extend this to a numpy array (vector, matrix...):

In [9]:
x = np.array([5,1,4,6,2])
print("x = ", x)
masque = (x >= 4) # parentheses are not obligatory but allow you to better distinguish the =
print("The condition x >= 4 returns", masque)

x = [5 1 4 6 2]
The condition x >= 4 returns [ True False True True False]

We created an array of Booleans mask, same size as x, which indicates whether the condition is true or false for each component from the table x. Using this mask, we can extract the values of x which satisfy this condition with the instruction:

In [10]:
x[x>=4]
Out[10]:
array([5, 4, 6])

We obtain a subset of x, of size 3, containing the components of x corresponding to the indices where the mask x>=4 is true. We can understand the term mask by imagining a painting that we position on the board x, and where the True correspond to “holes” which leave visible the “good” components of x. This vision is illustrated by the figure below:

By using a mask, we can also edit all values of x greater than or equal to 4 by assigning them the value 9:

In [11]:
x[x>=4] = 9
print("After the instruction x[x>=4] = 9, x = ", x)

After the instruction x[x>=4] = 9, x = [9 1 9 9 2]

The vector x is now modified.

Note: this is exactly the same syntax as when we want to modify a subset of x with for example x[1:4]=9, except that we used a mask rather than the set of indices 1:4 to indicate the components to modify.

Finally, for count the number of occurrences where the condition is true, we can use np.sum because internally the logical condition stored on a bit is worth 1 when the condition is true and 0 when it is false. For example:

In [12]:
masque = np.array([True, False,  True,  True, False])
nbTrue = np.sum(masque)
print("There is"+str(nbTrue)+"'True' elements in this array.")

There are 3 'True' elements in this array.

3 - Combine logic conditions: “short-circuit” and “bitwise” tests¶

It is common to combine several logical conditions. Tests can be costly in terms of calculation time and this is why in Python the notion of “shortcut” testing was created.

In the first example, we combined two conditions: $t \ge 1$ and $t \le 3$. The keyword used is not and as one would expect but a & :

  • the and is a test called short-circuit,
  • the & is a test called bitwise (bit-by-bit).

These two test families are used differently:

  • The short_circuit stops the test sequence as soon as the logical condition of the whole is verified. For example if we want to know the result of: 3>4 and 7<8:

    1. We test 3>4 which is false,
    2. there is no point wasting time testing 7<8 because whatever the result of this second test, the whole thing will be false.

  • On the contrary, the bitwise forces Python to do all the tests. In our example above with numpy arrays, we wanted to test all positions to retrieve corresponding indices and define subsets of arrays t and v. We therefore used vcut = v[(t>= 1) & (t <= 3)] with the bitwise test &.

In conclusion, the syntax is different depending on the type of test:

  • Short circuit: and, gold, not.
  • Bitwise: &, | , ~.

A somewhat pragmatic and easy to remember rule is that we generally use

  • the tests short-circuit with instructions if or the curls while
  • the tests bitwise for numpy arrays.
