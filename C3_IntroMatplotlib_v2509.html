Introduction : matplotlib, pyplot, graphes et réglage dans Spyder¶

matplotlib est une librairie Python pour faire des tracés de courbes et des figures de très bonnes qualités dans une grande variété de formats. Le site internet du projet est matplotlib.org. La documentation et surtout les exemples sur le site du projet ne sont malheureusement pas toujours très faciles à comprendre car ils se basent sur le matplotlib OO (orienté objet).

Nous utiliserons une syntaxe simplifiée qui est largement suffisante pour nos besoins. Cette syntaxe est simplifiée par l'interface pyplot qui est une sous-partie de matplotlib : matplotlib.pyplot

Pour commencer à utliser matplotlib.pyplot il faut importer la bibliothèque avec la ligne suivante. L'alias habituel est plt :

In [1]:
import matplotlib.pyplot as plt

Le réglage par défaut de Spyder est d'afficher les fenêtres graphiques dans un onglet "Graphes". Il est plus pratique d'afficher les figures dans des fenêtres indépendantes (fenêtres graphiques interactives), on demande donc dans cette UE de faire le réglage suivant :

Outils -> Préférences -> Console IPython -> Graphiques : régler "Sortie graphique" sur "automatique"

Ensuite, redémarrer Spyder (ou juste le noyau de la console IPython) pour que ces modifications soient prises en compte.

*Note : Ceux qui utilisent jupyter notebook (ce qui n'est pas recommandé pour ce cours) il faut rajouter la ligne magique :

%matplotlib auto*

1 - Un premier exemple¶

La syntaxe de matplotlib.pyplot est en général très intuitive.

Le code ci-dessous est le premier exemple de tracé de la fonction cosinus dans l'intervalle $[ 0, 2\pi ]$.

In [2]:
import numpy as np           # import de numpy pour accéder aux vecteurs
                             # et fonctions mathématiques (cf Cours 2)
import matplotlib.pyplot as plt # import de pyplot

x_points = np.linspace(0, 2*np.pi, 30) # définit un vecteur d'abscisses
y_points = np.cos(x_points)  # calcule des ordonnées

plt.figure(1)                # Ouvre une figure et lui attribue l'identifiant 1
plt.plot(x_points, y_points) # Trace y en fonction de x
                             # Attention au format : plt.plot(abscisses, ordonnées)
Out[2]:
[<matplotlib.lines.Line2D at 0x7f56946a8d30>]

Notez qu'on commence toujours par ouvrir une figure avec plt.figure(). Cela revient à "prendre une nouvelle feuille blanche" sur laquelle les commandes suivantes (comme plt.plot()) vont ajouter des tracés. Si vous omettez cette étape, tous les tracés de votre code vont se superposer sur une unique figure.

On peut fermer une figure avec la commande plt.close(). La commande plt.close(1) ferme la figure 1, plt.close('all') ferme toutes les figures.

2 - Réaliser un graphe scientifique¶

Si vous souhaitez tracer plusieurs courbes, il suffit d'appeler la fonction plot plusieurs fois. Ensuite, vous pouvez travailler sur la couleur et le style des lignes en ajoutant des arguments à la fonction plot comme ci-dessous. Vous pouvez également voir comment sont ajoutés les noms des axes, des légendes, etc. qui sont indispensables dans un graphique scientifique. Les commandes sont explicites si on comprend l'anglais.

In [3]:
import numpy as np

x_points = np.linspace(0, 2*np.pi, 30)
y1_points = np.cos(x_points)
y2_points = np.sin(x_points)

plt.figure(2)
# Précise couleur, style de ligne et de marqueur, épaisseur de ligne et étiquette (label) pour la légende
plt.plot(x_points, y1_points, color='blue', linestyle='-', linewidth=3, marker='o', label="cos")
plt.plot(x_points, y2_points, color='red', linestyle='--', linewidth=2, marker='x', label="sin")

# Ajoute titre et noms des axes, en spécifiant la taille de fonte
plt.title("Deux fonctions", fontsize=20)
plt.xlabel(r"Angle $\theta$", fontsize=16)  # On utilise LaTeX pour les lettres grecques 
                                            # Notez à la fois le r et les $$.
plt.ylabel("Cosinus, Sinus", fontsize=16)

plt.legend(fontsize=16) # Affiche la légende (en utilisant les labels de chaque tracé)
plt.xticks(fontsize=16) # Taille de fonte des graduations
plt.yticks(fontsize=16)
#plt.tick_params(axis='both',labelsize=20) # Variante pour changer la taille des fontes à 20 
                                           # sur les deux axes en une seule commande.
plt.xlim(0, 2*np.pi)    # Limites du cadre de la figure 
plt.ylim(-1.2, 1.2)
plt.grid()              # Grille en arrière-plan (facilite la lecture des coordonnées)

3 - Raccourcis pour les marqueurs, couleurs et styles de lignes¶

Au lieu de spécifier plusieurs arguments pour décrire le style d'une ligne, vous pouvez utiliser une notation raccourcie qu'on utilise majoritairement en pratique :

In [4]:
x_points = np.linspace(0, 2*np.pi, 30)
y_points = np.cos(x_points)

# Observez la notation raccourcie
plt.figure(11)
plt.plot(x_points, y_points, '-or', lw=2) # -or veut dire utilise un trait plein, des cercles et la couleur rouge
                                          # lw=2 est l'abréviation de linewidth=2 (épaisseur de ligne égale à 2).
Out[4]:
[<matplotlib.lines.Line2D at 0x7f5693cf0f10>]

De très nombreux marqueurs, styles de lignes et couleurs sont disponibles. Une liste (avec les abbréviations associées) est donnée dans la documentation de la fonction plot : https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.plot.html

On donne quelques exemples qui suffiront pour les besoins de cette UE :

  • Marqueurs : . (points), o (cercles), + et x (croix), ^, v, < et > (triangles)
  • Styles : - (plein), -- (tirets), : (pointillés)
  • Couleurs : k (black), b (blue), r (red)

4 - D'autres exemples : subplot, semilog, loglog¶

En principe, les exemples ci-dessus sont suffisants pour la plupart des besoins. Ci-dessous quelques exemples supplémentaires sont présentés. Vous pouvez notamment voir comment fonctionne la commande subplot qui permet de diviser une figure en sous-figures ou encore comment tracer en échelle semilogarithmique ou logarithmique (utile pour représenter des fonction exponentielles ou puissance).

In [5]:
#%% Tracé de deux fonctions plus complexes

FS = 16 # taille de fonte utilisée par la suite (modifiable ici si besoin au lieu de changer dans chaque commande)

xr = np.arange(0, 3, 0.01)
yr1 = np.exp(xr) * (np.sin(5 * xr))
yr2 = np.exp(xr) * (np.cos(5 * xr))

plt.figure(3)
plt.plot(xr, yr1, '-r', lw=2, label='une premiere courbe')
plt.plot(xr, yr2, '--b', lw=2, label='$e^{x} \cos(5 x)$') # Cette expression utilise LaTeX entre $ $ pour le label
plt.legend(fontsize=FS)
plt.xlabel(r'Temps $t$', fontsize=FS)
plt.ylabel(r'Fonction $f(t)$', fontsize=FS)
Out[5]:
Text(0, 0.5, 'Fonction $f(t)$')
In [6]:
#%% Utilisation de subplot (ici avec un axe des abscisses commun à deux figures)

plt.figure(4)

plt.subplot(2,1,1) # syntaxe : subplot(nb_lignes, nb_colonnes, n° subplot)
                   # (ici 2 lignes et une colonne donc deux sous-figures superposées)
                   # puis dans chaque subplot on peut faire des tracés, 
                   # ajouter des indications etc. comme dans une figure 
plt.plot(xr, yr1,'-r', lw=2, label='une premiere courbe')
plt.legend(fontsize=FS)
plt.ylabel(r'$f(t)$', fontsize=FS) 

plt.subplot(2,1,2) # ... on se place dans la deuxième sous-figure
plt.plot(xr, yr2, '--b', lw=2, label='$e^{x} \cos(5 x)$')
plt.legend(fontsize=FS)
plt.xlabel(r'Temps $t$', fontsize=FS) # On ne met qu'un xlabel pour les deux figures
plt.ylabel(r'$f(t)$', fontsize=FS)
Out[6]:
Text(0, 0.5, '$f(t)$')
In [7]:
#%% Subplot avec un axe des ordonnées commun

plt.figure(5)

plt.subplot(1,2,1) # une ligne, deux colonnes : deux sous-figures côte-à-côte
plt.plot(xr, yr1, '-r', lw=3, label='a first curve')
plt.legend()
plt.ylabel('Fonction $f(t)$')
plt.xlabel('Temps $t$')

plt.subplot(1,2,2)
plt.grid()
plt.plot(xr, yr2, '--b', lw=3, label='$e^{x} \cos(5 x)$')
plt.legend()
plt.xlabel('Temps $t$')
Out[7]:
Text(0.5, 0, 'Temps $t$')

Quand des parties de différents subplots se chevauchent (nom des axes, titres ...), on peut utiliser la commande plt.tight_layout() après avoir défini tous les subplots.

5 - Plus d'informations, documentation, quelques mots sur la programmation orientée objet (POO)¶

matplotlib peut faire beaucoup de choses. La meilleure stratégie consiste généralement à examiner des exemples (comme ceux du site web de matplotlib) et voir le code qui les a produites. Vous pouvez alors les adapter à vos besoins. Hélas, la syntaxe est parfois un peu ardue car comme mentionné en introduction, l'utilisation de matplotlib orienté objet peut s'avérer déroutante si on ne maitrise pas la programmation objet. Il faut copier avec prudence les exemples que l'on trouve sur les forums ou même sur la documentation officielle. Il est plutôt conseillé d'aller sur le tutoriel de matplotlib.pyplot.
