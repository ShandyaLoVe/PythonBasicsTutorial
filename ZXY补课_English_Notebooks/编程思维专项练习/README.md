# 编程思维专项练习

每道题是一个可以直接运行的 Python 文件：

- `exercise_01.py` 到 `exercise_12.py`：题目说明、作答函数、测试函数在同一个文件中。
- `exercise_02_input.txt`：第 2 题读取的拉伸试验日志；运行第 2 题后会生成 `exercise_02_report.txt`。
- 直接运行单个文件，会显示“成功”“失败”或“报错”。
- 运行 `python run_all.py`，可以依次检查全部题目。
- 当前函数体保留为练习接口；完成函数后重新运行对应文件即可。

题目使用力学实验和工程场景，练习点仍对应课程中的基础 Python、NumPy、绘图、文件处理和经典算法。
